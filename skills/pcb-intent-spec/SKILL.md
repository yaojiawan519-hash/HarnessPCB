# 放置审查清单（原「意图 spec」）

> **v0.2 起 intent.json 已停用**：RL 放置线退役，place 步换成规则摆件
> （`skills/pcb-place` 四条规则）。所以本 skill 不再教怎么"写 spec"，
> 只保留两样**换引擎也不会变**的东西：摆之前该数清什么、交付时该拿什么对数。
> 历史格式见 `docs/输入格式说明.md` §二（已折叠存档）。

## A. 摆之前先数清（防漏项）

> 学费：一块板 10 个连接器只盯住 8 个，剩下两个把主控拖偏 52mm，
> 随后几十组调参实验全部白跑——**漏项不是调参能修的**。
> 规则摆件会**自动**处理"接口一面朝外"，但"哪些件算接口"它只认封装与外接网，
> 机械件、按键、测试点它认不出来——这部分仍要人来数。

- [ ] **A1 连接器/机械件全量点名**：从原理图数出全部连接器、按键、开关、
  安装件的位号，与板上实际件对账，一个不许少。落单的接口件不会被规则摆件
  当成"嘴"，它会留在板中间——自己挪。
- [ ] **A2 无嘴件要单独说**：单排直插排针没有"嘴"，规则是脚排平行于所贴边；
  按键/测试点没有嘴。别指望规则自动摆对，摆完逐个看。
- [ ] **A3 关键局部结构点名**（没有的写「无」，空缺≠明确没有）：
  晶体+负载电容 / 去耦电容环 / 电源簇 / Buck 高频环路+反馈网络 /
  ESD 入口、端接电阻。
- [ ] **A4 噪声源↔敏感对象成对点名**：开关节点/时钟/大电流 vs
  晶体/高阻输入/基准。
- [ ] **A5 热源与热敏件**：功率器件意向、散热铜皮；小功率板写「无」。
- [ ] **A6 已知工艺量**：层数/参考平面/最小线宽线距——布线 clearance
  阶梯起点档的依据。
- [ ] **A7 三个旋钮定下来**：`--face`（接口朝哪面）/ `--gap`（件间净距，
  默认 0.45，挤就放大）/ `--ports`（口岸网名）。**给错 `--ports` 等于给错的嘴**，
  独立摆一块不接外部的板就别给。

## B. 交付时逐条对数

- [ ] **B1 硬约束零违规**：连接器全在边上、开口朝外；courtyard 重叠 0。
- [ ] **B2 关键结构落地有数字**：去耦最远中心距（应 ≤2.2mm 量级）、
  "N/M 只超 2.2mm"（应 0/M）、晶体到芯片时钟脚的净距、孤儿电容数——数字说话。
  `place_rules.py --dry-run` 直接打印这几行，别凭眼看。
- [ ] **B3 数字表不倒退**：HPWL、关键器件对距离、均匀度，与上一轮对照；
  只看「看起来顺眼」不算验收。
- [ ] **B4 试布线跑过且失败有分类**：死网归因到器件级
  （`skills/pcb-route-session` 的 blockers），「细脚距逃逸」与「顺序残余」
  分开记；引擎搜不到 ≠ 布局无解。
- [ ] **B5 局部改动无全局副作用**：搬一件后全板重测——规则摆件是**确定性**的，
  改一个旋钮就是整块重排，不是只动那一件；改动前后留档。
- [ ] **B6 布线读数**：首过档位、孔数、100% 布通/0 铜级
  （`skills/pcb-chain` / `skills/pcb-drc-read` 口径）。
- [ ] **B7 电源网空线头抽查**：DRC + 焊盘归属 + 悬空端点三重验。
- [ ] **B8 交付件齐**：放置图 + 布线图 + 数字表 + 对照说明。

## 铁律

- 接新板**先过 A 段**再跑 place；交付时 B 段打勾留痕。
- 规则摆件没有 seed、没有权重——**同样输入永远同样输出**。所以"跑两遍碰运气"
  不存在，改不动就改旋钮或改规则，别重试。
- 未落位/未识别要如实报，不猜不粉饰。
