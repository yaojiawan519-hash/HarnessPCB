# 放置意图 spec（写前检查 + 交付验收）

intent.json 格式见 `docs/输入格式说明.md` §二（items/power_cluster
字段表）；本 skill 管的是**写 spec 前把漏项当场抓住**，和**交付时
逐条对数**。设计表的 multi/pwr_flags 学问见同文档 §3/§7。

## A. 写 spec 前过一遍（防漏项）

> 学费：一块板 10 个连接器只锁 8 个，漂浮的两个把主控拖偏 52mm，
> 随后几十组调参实验全部白跑——**漏项不是调参能修的**。

- [ ] **A1 连接器/机械件全量点名**：从原理图数出全部连接器、按键、
  开关、安装件位号，与 intent `items` 键集合对账，一个不许少。
- [ ] **A2 每条 edge/along 有出处**：人工板量得 / 板框比例 / 外壳约束，
  出处写进备注；不许拍脑袋。
- [ ] **A3 生成命令默认锁连接器**：chain/place 不带 `--no-fix-connectors`
  （实验臂除外，且须注明）。
- [ ] **A4 关键局部结构点名**（没有的项写「无」，空缺≠明确没有）：
  晶体+负载电容 / 去耦电容环 / 电源簇（anchor/depth/margin/gap）/
  Buck 高频环路+反馈网络 / ESD 入口、端接电阻。
- [ ] **A5 噪声源↔敏感对象成对点名**：开关节点/时钟/大电流 vs
  晶体/高阻输入/基准。
- [ ] **A6 热源与热敏件**：功率器件意向、散热铜皮；小功率板写「无」。
- [ ] **A7 已知工艺量**：层数/参考平面/最小线宽线距——布线 clearance
  阶梯起点档的依据。
- [ ] **A8 pad_clear ≥ 板边铜距约束**：`pad_clear_mm` 必须 ≥ 板设置的
  copper-edge clearance（KiCad 默认 0.5mm）+ 裕量，否则贴边连接器焊盘
  直接触发 `copper_edge_clearance` 铜级硬项拦链（学费：demo 意图初版
  0.3mm < 0.5 板规，place 忠实执行、DRC 如实拦下——错在 spec 不在引擎）。

## B. 交付验收时逐条对数

- [ ] **B1 硬约束零违规**：连接器全锁、外沿凸出、开口朝外；
  courtyard/板框合法化零违规。
- [ ] **B2 关键结构落地有数字**：电容环颗数、晶体近邻距离、电源簇
  成员在带内、孤儿电容数——数字说话。
- [ ] **B3 数字表不倒退**：HPWL、关键器件对距离、均匀度，与上一轮
  对照；只看「看起来顺眼」不算验收。
- [ ] **B4 试布线跑过且失败有分类**：死网归因到器件级
  （pcb-route-session blockers），「细脚距逃逸」与「顺序残余」分开记；
  引擎搜不到 ≠ 布局无解。
- [ ] **B5 局部改动无全局副作用**：spec 增补/搬位后全板重测——intent
  投影会连锁重排，不是只动那一件；改动前后留档。
- [ ] **B6 布线读数**：首过档位、孔数、100% 布通/0 铜级
  （pcb-chain / pcb-drc-read 口径）。
- [ ] **B7 电源网空线头抽查**：DRC + 焊盘归属 + 悬空端点三重验。
- [ ] **B8 交付件齐**：放置图 + 布线图 + 数字表 + 对照说明。

## 铁律

- 接新板**先过 A 段再写 intent**；交付时 B 段打勾留痕。
- 意图落位上报（edge/along/rot 三级信号）如实读——未落位会写明
  原因，不猜不粉饰。
