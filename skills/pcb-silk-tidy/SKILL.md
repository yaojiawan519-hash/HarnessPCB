# 丝印清理（silk tidy）

DRC 口径里丝印类是容忍项（见 pcb-drc-read）——不清理也能交付；
要清理时按下面五条来（真实板 r9 轮验证的方法学，GUI pcbnew 或
脚本皆可，工具无关）。

## 五条方法

1. **按真实文本框算位置，不按字数估**。KiCad 丝印文本占位约
   2.2 × 1.7 mm（1.27mm 网格下一格宽再多）——挪位/避让按这个真实
   框规划，按「几个字符大概多宽」估必翻车。
2. **QFP/QFN 丝印盲区用体框代替**。细脚距芯片正上方丝印位号会被
   自己的焊盘区吃掉（silk_over_copper）；把位号挪到芯片体框
   （courtyard/fab 层矩形）外侧短边处，别硬塞进芯片底下。
3. **竖排文本破无解**。板边/窄缝里横排放不下时，把文本转 90°
   竖排（沿板边方向）——很多「放不下」其实是方向问题。
4. **`silk_over_copper` 只算 F.Cu**。KiCad 这条检查只对正面丝印 vs
   正面铜（B.SilkS vs B.Cu 同理但两面独立）；背面丝印压的是正面铜
   不报。清理时别在错误的面上白忙。
5. **改丝印用属性 API 名**。脚本改位号文本时，KiCad 9/10 的字段
   名是 `reference`/`value`（fp_text 的用途属性），不是显示文本
   本身——改错对象会「看起来改了其实没改」。

## 工作流

1. DRC 报告里数丝印类条目（pcb-drc-read 口径），按 kind 分组。
2. 优先级：位号被铜吃掉（装配识别不了）> 丝印互相重叠 > 丝印压
   板边（`silk_edge_clearance`，被铣掉）。
3. 逐条挪（一次一处），挪完重跑 DRC 确认只减不增。
4. 丝印级改动后**不需要**重跑布线——它不碰铜。

## 铁律

- 只动 F.SilkS/B.SilkS 层对象与文本属性，任何铜层/Edge.Cuts 不碰。
- 挪完 DRC 复核：铜级必须仍是 0（丝印操作理论上碰不到铜，
   复核是防手滑）。
