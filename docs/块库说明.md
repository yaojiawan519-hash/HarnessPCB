# 块库说明（108 块）

`blocks/` 里每一块，都是**从真实开源板上一件一件、一截铜一截铜扣下来的电路**，
不是程序生成的。原封不动搬过来，图纸、封装、人手画的走线一个字都没改。

一句话：**这是菜单**。设计新板时，能整块复用的就别重画；AI 或人从 `blocks/index.json`
里挑，挑中哪块就直接用哪块。

## 一块里有什么

```
blocks/<块名>/
├── block.sdi.yaml          块卡：端口 / 轨 / 内部网 / 件表 / 连线 / 放置先验 / 出处与许可
├── <块名>.kicad_sch        原理图（作者原图，按分区框整框裁出）
├── <块名>.kicad_pcb        板（作者原板按位号原样扣铜）
├── <块名>.kicad_pro        工程设置（板规等，DRC 要用）
├── <块名>.table.json       块卡回读产物
├── <块名>.semantic.json    语义产物
├── <块名>.placement.json   几何清单：件/网/铜段/孔/口岸切口/借道块外焊盘
└── _geom/
    ├── measured.json       实测几何（权威：几何以它为准）
    └── drc.json            这块板自己的 DRC 结果
```

另有 `blocks/INDEX.md`（人看）与 `blocks/index.json`（机读，检索用）。

## 六条硬规矩（都是踩出来的，不是规定出来的）

1. **完全截取**：块内一个数都不动。要改必须是点名的手术（`surgery:` 里逐条记账，
   写清删了什么、为什么）。做不到"原样"就别用这块。
2. **块板不带铺铜**：拼板时要整板重铺，块里留着自己那点铺铜，反倒把别人的走线挡死。
   **唯一例外**是内部网的载流铺铜（比如 buck 的 SW→L1 那段，删了电路就断了）。
3. **块板一律 2 层**：不做中间层平面。走不通就换布线器，别加层。
   ⚠ 现状不齐：随包 108 块里 **67 块 2 层、38 块还是 4 层**（那 38 块的内层里有作者
   真画的铜，收层会把人的东西删掉，属待处理账，不是忘了）。
4. **口岸按焊盘记**：拼装时从焊盘重新拉线。扣块时人的铜会在块边界被剪开，剪剩的
   尾巴按"空线头清零"的规矩删掉——**块里的出口铜本来就对接不上邻块**，别指望它。
5. **空线头必须清零**：交付板的悬空线头只能是点名记账的口岸断头，或试删门证明
   删了会断网的载流断头。毛刺一根不许留。
6. **无名内部网必须登记**：块里没有网名的内部连接要进 `internal_nets`，
   否则同一块放两份会静默并网。

## 三条用法上的实话

- **GND 和电源轨在块里是碎的**。不带铺铜 + 收 2 层 = 原板靠平面供电的
  `+3V3`/`GND` 在各块里裂成好几坨（`<块名>.placement.json` 的
  `counts.island_split` 逐网记着裂了几岛，如 `{"+3V3": 3, "GND": 6}`）。
  拼板时必须整板重铺 GND、并把电源主干重新拉出来，否则 LDO 送了电也到不了 MCU。
- **借道块外焊盘的网，单看这块是断的**。作者原本让一根线穿到块外换层，
  那孔不在块里。`placement.json.counts.borrowed_pads` 逐条记着
  （如 `SPI3_!CS→U4.2`），拼板插上就通。
- **块是电路分组，不一定等于布局分组**。作者按功能画的分区框，所以有的块是
  "芯片本体"，晶振、天线匹配网络各是另一块——摆的时候它们得挨着。

## 怎么用

```bash
# 全库体检（四道门：卡↔板 / 卡回读 / 短路 / 空线头）
python3 -m sdi.checkall blocks

# 单块体检 + 块卡回读
python3 -m sdi card --root . blocks/<块名>
```

（在 `executors/DesignBlockTools` 目录下跑；`sdi` 要 PyYAML，**用包内 venv 的
python** —— `executors/Placement/.venv/bin/python`，它随 `kicad-access` 装了 pyyaml。）

要拿块拼整板，走 `sdi.blockpcb` / `sdi.unify`；摆件规则见 `skills/pcb-place`。

## 许可证

**只收 `license_tier: permissive`**（上游 MIT/Apache 等，可公开发行）。
每块卡的 `provenance` 里写着上游作者、版权行与来源板。

被挡在外的两类，一块都没进这个仓库：

- `internal`（30 块）—— 用户自己的板或许可未核定；
- 无块卡（20 块）—— 早期引擎生成的块，没有许可证记录，证不了就等于没有。

重新打包时这两类是**整批拒绝**，不是警告：`tools/pack_blocks.py` 只认
`permissive`，别的连复制都不做。
